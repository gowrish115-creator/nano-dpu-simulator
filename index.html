🔧 Test Instruments

This panel stands in for the weighing scale and milk analyzer that plug into the real DPU. Enter a value, then press Send, or use Read Scale / Read Analyzer on the screen.
⚖ Weighing scale
Works on: Add Purchase, Add Sale, Sample Milk.
🧪 Milk analyzer
Works on: Add Purchase, Sample Milk.

Nano Instruments · DPU app replica, matched screen-by-screen to the real NanoDairy app (app-releaseV2.0.85.apk + 30 screenshots). Fully interactive: Add Member / Purchase / Sale / Advance all write to their lists and recompute totals; Advance View + Print Preview, dual VLCC/CC averages, and all report filters included. Rate uses a sample formula (the real chart is server-pushed). Producer avatar, NANO logo and the "No Data Found" illustration use the app's own image assets extracted from the APK.
